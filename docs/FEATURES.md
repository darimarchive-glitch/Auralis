# Auralis feature contract

A 3.1.x build is considered functionally complete only when these flows work:

1. Import EPUB/PDF/TXT/Markdown/HTML/DOCX/FB2/RTF.
2. Persist library, reading position and preferences.
3. Extract an embedded cover or attempt a confidence-scored online cover lookup.
4. Open any book from the bottom navigation without restarting the app.
5. Narrate the active original or translated text.
6. Expose real voices reported by the operating-system TTS engine and remember the selected voice.
7. Synchronize narration position with displayed text whenever the engine reports word positions.
8. Translate pasted text or a complete book in chunks, preserving chapter boundaries and cached results.
9. Switch between original and translated text.
10. Use audiobook mode with chapter progression and sleep timer.
