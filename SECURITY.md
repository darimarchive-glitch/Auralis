# Security

Nunca adicione ao repositório chaves de API, tokens, keystores, senhas,
credenciais de assinatura ou arquivos `.env` privados.

As chaves de tradução inseridas no aplicativo pertencem ao usuário e ficam no
armazenamento local da instalação. Builds públicos usam somente credenciais
temporárias fornecidas pelo GitHub Actions quando necessário para publicar uma
release.
